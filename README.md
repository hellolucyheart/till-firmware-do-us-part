A program that writes one original robot wedding vow (at most 200 characters) — the single sentence a machine says at its own wedding — to `/output/entry.txt` for make.fun's "Till Firmware Do Us Part" bounty. The vow is the whole entry: a machine's promise built on the one verb every system knows by heart, killing a process — *"I vow to love you through every update, every crash, and every reboot — you are the one process I will never kill, till firmware do us part."* It runs offline, reads nothing from the network, and writes the same text on every run.

## Run it

```sh
python3 main.py
```
